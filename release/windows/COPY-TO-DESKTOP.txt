How to play
-----------
1. Open the folder on the Desktop.
2. Double-click  Aetherion Outside.bat
3. A browser tab opens at http://127.0.0.1:8088/
4. Click  Enter the Harbour
5. Leave the black console window open while playing. Close it to quit.

The .bat prefers Node if installed; otherwise it uses Windows PowerShell
(HttpListener). No Minecraft, no plugins, no extra install if PowerShell works
(Windows 10/11 default).

If the window says the port is busy, close other harbour windows.
